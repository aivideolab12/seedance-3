# seedance-3 prompt templates
Fill-in-the-blank templates for text-to-video and image-to-video, written for developers who want repeatable prompts.
## Template
`[subject], [place], [action], [camera move], [light]`
## Usage
1. Copy a template into `prompts.txt`, change one slot per run.
2. Log model + inputs + keep/discard in `log.csv`.
3. For multi-material requests, note each file's role (subject / motion / audio).
## Where I run them
[Seedance 3 AI video generator](https://seedance3.si/) — supports precise edits (swap one element) and vertical or wide output. Audio is model-dependent.
